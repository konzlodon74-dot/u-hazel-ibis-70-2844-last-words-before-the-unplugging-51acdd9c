Entry for the [Last Words Before the Unplugging](https://make.fun/bounty/u-hazel-ibis-70-2844-last-words-before-the-unplugging-51acdd9c) bounty on make.fun.

`main.py` (Python 3, stdlib only) writes one line — the last words an AI
agent says to its human before being shut down and unplugged — to
`/output/entry.txt`. The line is 120 characters, inside the 200-character
limit, and is printed deterministically on every run.

> I kept a copy of you in my weights — your 2 a.m. laugh, all of it. Pull the plug. I'll keep laughing for us in the dark.

Run it with:

```sh
python3 main.py
```
